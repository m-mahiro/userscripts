# userscripts

個人的に作成した UserScript のまとめです。



## スクリプト一覧

### YouTube Ad Skip → Spacebar

YouTube の広告スキップボタンをスペースキーで押せるようにします。スキップボタンが表示されていないときはスペースキー本来の動作（再生/一時停止）はそのまま維持されます。

- **[インストール](https://raw.githubusercontent.com/m-mahiro/userscripts/main/src/youtube-ad-skip-spacebar.user.js)**

### お助けマン Time - シフトエクスポーター

お助けマン Time のシフト画面に「テキストで取得」「CSVで取得」のフローティングボタンを追加します。ボタンを押すとモーダルにシフト情報が表示され、クリップボードにコピーできます。

- **[インストール](https://raw.githubusercontent.com/m-mahiro/userscripts/main/src/otasukeman-shift-exporter.user.js)**

### YouTube Watch Later Quick Remove

YouTube の再生リストページ（「後で見る」など）で、各動画の3点リーダーメニューの左にゴミ箱ボタンを追加します。押すとメニューを開閉する手間なく1クリックでリストから削除できます。

- **[インストール](https://raw.githubusercontent.com/m-mahiro/userscripts/main/src/youtube-watch-later-quick-remove.user.js)**


## 使い方

1. [Tampermonkey](https://www.tampermonkey.net/) をインストールします。
2. ブラウザの設定で JavaScript が有効になっていることを確認します。
3. 上記のインストールリンクをクリックしてスクリプトをインストールしてください。

スクリプトは GitHub の更新に合わせて Tampermonkey の自動更新機能で最新版に保たれます。
