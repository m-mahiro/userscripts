# userscripts

個人的に作成した UserScript のまとめです。

---

## スクリプト一覧

### YouTube Ad Skip → Spacebar

YouTube の広告スキップボタンをスペースキーで押せるようにします。スキップボタンが表示されていないときはスペースキー本来の動作（再生/一時停止）はそのまま維持されます。

- **[インストール](https://raw.githubusercontent.com/m-mahiro/userscripts/main/src/youtube-ad-skip-spacebar.user.js)**

---

## 使い方

1. [Tampermonkey](https://www.tampermonkey.net/) をインストールします。
2. ブラウザの設定で JavaScript が有効になっていることを確認します。
3. 上記のインストールリンクをクリックしてスクリプトをインストールしてください。

スクリプトは GitHub の更新に合わせて Tampermonkey の自動更新機能で最新版に保たれます。
